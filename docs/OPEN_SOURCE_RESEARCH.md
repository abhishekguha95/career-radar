## Official ATS checks

- [Lever Postings API](https://github.com/lever/postings-api): public published posts may be scraped by third parties; `skip`/`limit` pagination; primary/all locations, country, commitment, description components, workplace type, hosted/apply URLs. Application POST limits are not assumed to be GET quotas. Global/EU API hosts are documented. No guaranteed GET quota was found; use conservative pacing and respect 429/Retry-After. Public API availability does not transfer posting copyright.
- [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html): GET endpoints require no authentication; content-enabled list; separate posting/internal-job IDs; updated timestamps. Useful alternative when employer coverage favors it.
- Planning check: one bounded GET to Lever's `lever` site returned HTTP 200 and an empty array. This establishes reachability only; mapping against nonempty live data remains unverified at this point.
- Implementation acceptance: a bounded GET through the completed adapter to the documented `leverdemo` site accepted and stored 10 postings. The one-full-page cap correctly produced PARTIAL/PAGE_LIMIT. See VERIFICATION.md; broader employer coverage is still unmeasured.

Keep MIT for original Career Radar code. Review attribution, applicable notices, dependencies, and data permissions separately before any future reuse.
