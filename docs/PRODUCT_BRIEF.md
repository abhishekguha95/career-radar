# Product brief

Career Radar is a local-first, open-source decision-support system for engineering job searches. It evaluates candidate fit and career value independently, with evidence and uncertainty visible. It is not an automatic application service.

The initial user is a senior backend engineer based in Pune, India, experienced in Node.js/TypeScript, databases, asynchronous systems, AWS, architecture ownership, and reliability. Desired growth includes Go, distributed systems, Kafka, Kubernetes, and AI infrastructure.

Search tracks:
1. Remote roles explicitly compatible with residing in India.
2. European relocation: Nordic countries first, Germany/Netherlands second; sponsorship must be verified separately.
3. Stretch opportunities with stated gaps, separated from verified actionable work.

Eligibility, technical fit, career fit, and recommendation remain distinct. Vague remote wording cannot establish India hiring eligibility. Relocation benefits cannot establish sponsorship.

Phase 1 delivers ATS ingestion, normalization, PostgreSQL storage, change evidence, a narrow geography signal, and a read-only API. Profiles, ranking, applications, resume generation, and external submissions are deferred.
